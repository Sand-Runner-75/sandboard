    Signed out

    Sign in to read your projects

    Sandboard shows your projects' tasks and progress exactly as your plan repository records them. It only reads: nothing here can change a plan, a task or a repository. Nothing is loaded until you sign in, and nothing you load is kept after you leave.

    The token stays in this page's memory only. Leaving, reloading or "Forget access" drops it and everything read with it.

    Keyboard

    Ctrl K ⌘K
    Go to a project, a view or a task
    /
    Search tasks; Account → Search finds words in everything already read
    ↑ ↓ Home End
    Move in the tree and in the task list
    → ← in the tree
    Open a group, close it or go to its parent
    Alt ↑ Alt ↓ on a project
    Move the project up or down in the tree (or drag it); the order is kept in this browser only
    Enter
    Open the item; in the task list, show its details
    T
    Open the task as a tab
    ← → on tabs
    Move between tabs; Delete closes one
    ← → on a task tab's sections
    Move between Details, Brief, Handover, Results, Cross-references and Related
    G then a letter
    Go to: H Home, P Progress, A Atlas, T Timeline, C Calendar, M Members, E Teams, I Inbox, S Search, R All repositories; D switches between dark and light
    Shift F10 or the menu key
    On a project or a task: open it, star it, or copy or open its GitHub link (right-click does the same)
    Esc
    Hide an explanation bubble; close the details, this help or Go to

    Sandboard only reads until you turn on Edit mode with a separate write token. In Edit mode every change is shown in full and sent only after you confirm it.

    Words used here

    The same explanations appear in a bubble when you rest the pointer on a word or move to it with the keyboard. Esc hides the bubble.

    Go to

      Goes to places and runs a few commands that change only what is shown. To find words in the tasks, pull requests and files already read, go to Search.

      Turn on Edit mode

      Paste a separate fine-grained token with write permissions, made on GitHub for one owner and only the repositories you choose. It stays in this page's memory only, apart from the read token, until you leave Edit mode, sign out, reload or close the tab. Nothing is sent until you confirm each change.

      Confirm this change

      This is exactly what will be sent to GitHub. Changing anything means confirming again.
