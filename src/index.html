Sandboard read-only

    Signed out

    Sign in to read your projects

    Sandboard shows your projects' tasks and progress exactly as your plan repository records them. It only reads: nothing here can change a plan, a task or a repository. Nothing is loaded until you sign in, and nothing you load is kept after you leave.

    The token stays in this page's memory only. Leaving, reloading or "Forget access" drops it and everything read with it.

    Keyboard

    Ctrl K ⌘K
    Go to a project, a view or a task
    /
    Search tasks
    ↑ ↓ Home End
    Move in the tree and in the task list
    → ← in the tree
    Open a group, close it or go to its parent
    Enter
    Open the item; in the task list, show its details
    T
    Open the task as a tab
    ← → on tabs
    Move between tabs; Delete closes one
    ← → on a task tab's sections
    Move between Details, Brief, Handover, Results, Cross-references and Related
    Esc
    Hide an explanation bubble; close the details, this help or Go to

    Sandboard only reads. There is no button that edits, assigns, merges, reviews, re-runs or publishes anything.

    Words used here

    The same explanations appear in a bubble when you rest the pointer on a word or move to it with the keyboard. Esc hides the bubble.

    Go to

      Goes to places only. It does not search inside files, pull requests or decisions.
